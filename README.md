# 💼 Laboratorio 2: Diseño Web con HTML5 y CSS3

HTML5 y CSS3 se utilizan para estructurar y diseñar páginas web profesionales. HTML5 provee la semántica y los contenedores de datos (como tablas y secciones), mientras que CSS se encarga del aspecto visual aplicando estilos mediante un juego de reglas específicas. El navegador interpreta el código estructurado y las hojas de estilo en cascada para renderizar una interfaz limpia, legible y responsiva.

Este repositorio contiene la solución de las actividades requeridas, permitiendo un dominio práctico en la organización modular de información y la refactorización con estilos externos. Algunos de los temas que se realizaron son los siguientes:

🔹 Configuración de metadatos en la cabecera (`<head>`, charset, viewport)  
🔹 Maquetación semántica y estructural (`<section>`, `<footer>`, `<main>`, `<aside>`)  
🔹 Estructuración de datos tabulares complejos (`<table>`, `<tr>`, `<td>`, `<th>`)  
🔹 Implementación de hipervínculos seguros (`<a>`, target, rel)  
🔹 Aplicación de selectores CSS (etiquetas, clases e identificadores)  

## 🌐 Tecnologías utilizadas
* 🛠️ HTML5
* 🛠️ CSS3
* 🛠️ Navegadores Web 
* 🛠️ Visual Studio Code

## 🚀 Conclusión
Esta experiencia me permitió entender que un documento CSS está compuesto por una colección de reglas donde el uso correcto de los **Selectores** es fundamental. El selector determina con precisión a qué elementos del árbol HTML se aplicará el diseño visual; si este no es válido, el navegador ignorará por completo el bloque de declaraciones. Mientras que HTML5 define el significado y la jerarquía de los datos, el verdadero control visual independiente se logra mediante la modulación de clases, identificadores únicos y selectores de etiquetas en cascada.
